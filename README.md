## Getting set up

1. **Create your account** at [graftlync.co.uk/signup](https://graftlync.co.uk/signup).
2. **Wait for approval** — the admin sets your role. Until then the app shows "Waiting for approval". You'll get an email when you're approved.
3. **Install the app** on your Android phone:
   1. Tap the download link above **on your phone**.
   2. Open **GraftLync.apk** from the download notification (or Files → Downloads).
   3. When the phone says it can't install unknown apps from this source, tap **Settings**, turn on **Allow from this source**, then go **Back**.
   4. Tap **Install**. If Play Protect asks, tap **More details → Install anyway**.
   5. Open the app and allow **Notifications** and **Location — Allow all the time** (used to fill in your site arrival/leave times).
4. **Sign in** with the email and password you signed up with — same details on the app and at [graftlync.co.uk/login](https://graftlync.co.uk/login).

## Updating

Download the newest APK from the same link and install it over the top — you stay signed in.
If the phone says **"App not installed"**, uninstall the old GraftLync first, then install again.
